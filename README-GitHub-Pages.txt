ชุดไฟล์ กกบ. Minutes สำหรับ GitHub Pages

อัปโหลดไฟล์ทั้งหมดในชุดนี้ไว้ที่ root ของ repository สาขา main แล้ว commit เพื่อเผยแพร่ด้วย GitHub Pages

ไลบรารี PDF/Office, OCR ภาษาไทย และ FFmpeg อยู่ระดับเดียวกับ index.html เพื่อให้อัปโหลดผ่านหน้าเว็บได้โดยไม่ต้องสร้างโฟลเดอร์ย่อย

FFmpeg ใช้ ffmpeg-core.wasm.gz ซึ่งแอปจะคลาย gzip ในเบราว์เซอร์ ส่วนโมเดล Whisper.cpp ขนาดใหญ่ใช้กับแอปบนเครื่องและไม่ได้รวมในหน้า GitHub Pages
